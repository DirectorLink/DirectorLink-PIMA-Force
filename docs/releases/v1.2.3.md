# DirectorLink · PIMA FORCE 1.2.3

Free, open-source Control4 driver for PIMA FORCE alarm panels. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

DirectorLink is an independent project, not affiliated with Control4, Snap One or PIMA.

## What's fixed

- **No Armed flash when you disarm during the exit delay.** A FORCE reads armed from the start of its exit delay, so Control4 and DirectorLink showed the partition Armed for a moment before Ready. Now it shows Ready as soon as the panel accepts the disarm.

Also in this version, from 1.2.2: the typed code again, so arming and disarming from DirectorLink is quick (1.2.0 and 1.2.1 took about 15 seconds a command).

## Updating

Download `DirectorLink-PIMA-Force.c4z` below, then in Composer **Driver → Add or Update Driver or Agent**. It updates 1.2.x in place.

`SHA256SUMS.txt` lists the package's checksum.
