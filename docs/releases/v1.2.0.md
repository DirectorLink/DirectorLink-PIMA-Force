# DirectorLink · PIMA FORCE 1.2.0

Free, open-source Control4 driver for PIMA FORCE alarm panels. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

DirectorLink is an independent project, not affiliated with Control4, Snap One or PIMA.

## What's new

- **Your alarm code stays out of Control4's logs.** With DirectorLink 1.16.0 every arm and disarm is sealed to this driver, which alone can open it. Control4's own debug log, which records the commands between drivers, sees only scrambled text.
- **Without a code, if you choose:** the new **DirectorLink Without Code** property (No, Arm only, Arm and disarm) lets DirectorLink arm, or arm and disarm, with the driver's Panel User Code. It stays No unless you change it, and DirectorLink's admins must allow it too.
- Works with DirectorLink 1.15.0 as before.

## Updating

Download `DirectorLink-PIMA-Force.c4z` below, then in Composer **Driver → Add or Update Driver or Agent**. It updates 1.1.0 in place.

`SHA256SUMS.txt` lists the package's checksum.
