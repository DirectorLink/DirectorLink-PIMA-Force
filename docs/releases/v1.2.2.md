# DirectorLink · PIMA FORCE 1.2.2

Free, open-source Control4 driver for PIMA FORCE alarm panels. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

DirectorLink is an independent project, not affiliated with Control4, Snap One or PIMA.

## What's fixed

- **Arming and disarming from DirectorLink is quick again.** 1.2.0 and 1.2.1 sealed each command from DirectorLink to this driver. On the controller, opening it took about 14 seconds, and Control4 waited meanwhile: the app could say a command failed that then went through, and Composer froze when the driver was updated. 1.2.2 takes the typed code again, as 1.1.0 did.
- **No Armed flash when you disarm during the exit delay:** Control4 and DirectorLink show Ready straight away.
- **DirectorLink Without Code is removed**, since it needed the sealed commands. Each arm and disarm from DirectorLink asks for your alarm code.
- As in 1.1.0 and with any Control4 alarm, the typed code passes through Control4's own debug log, which only the controller's root user can read and which is gone within a few hours.

## Updating

Download `DirectorLink-PIMA-Force.c4z` below, then in Composer **Driver → Add or Update Driver or Agent**. It updates 1.2.0 or 1.2.1 in place.

`SHA256SUMS.txt` lists the package's checksum.
