# DirectorLink · PIMA FORCE 1.0.0

Free, open-source Control4 driver for PIMA FORCE alarm panels (FORCE, FORCE 32C, FORCE 16). Part of [DirectorLink Drivers](https://directorlink.io/drivers).

DirectorLink is an independent project, not affiliated with Control4, Snap One or PIMA.

## What's in it

- **The panel connects to the driver** on the controller, the way it connects to a monitoring station: no cloud and no extra hardware.
- **With PIMA's JSON interface:** arm Away, Home and Night and disarm from Control4 (disarming needs a typed code, which the panel checks), alarms, troubles, zones with their names (Hebrew too), bypass and outputs 1-8.
- **Receive only,** for firmware without the JSON interface (like 1.5.1): the panel's standard SIA DC-09 reports show arming, disarming, alarms, troubles and zones in Control4.
- **DirectorLink's alarm agreement:** `DIRECTORLINK_ALARM_CONTROL` tells DirectorLink (1.15.0 and later) when arming and disarming can work, and an arm or disarm from DirectorLink is never carried out without the code a person typed.

## Tested

- Receive only on a FORCE 32C (firmware 1.5.1): arming Away and disarming showed in the partition each time.
- The JSON interface against a simulated panel (75 offline tests, also run on the packaged script). Reports from panels with JSON firmware are welcome in [Issues](https://github.com/DirectorLink/DirectorLink-PIMA-Force/issues).

## Installing

Download `DirectorLink-PIMA-Force.c4z` below, then in Composer **Driver → Add or Update Driver or Agent**. Setup: [README](https://github.com/DirectorLink/DirectorLink-PIMA-Force#setup).

From the earlier `PimaForce.c4z` test builds: this is a new driver for Composer. Remove **PIMA FORCE**, add **DirectorLink · PIMA FORCE**, and set its properties again (see the [change log](https://github.com/DirectorLink/DirectorLink-PIMA-Force/blob/main/CHANGELOG.md)).

`SHA256SUMS.txt` lists the package's checksum.
